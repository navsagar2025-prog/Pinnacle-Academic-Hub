Pinnacle Academic Classes — Revised Full Platform Build Prompt

Project Goal
Build a static demo/showcase SPA for Pinnacle Academic Classes, operated by KCK Corporate Services Pvt. Ltd. The platform should visually simulate a complete coaching institute website with role-based portals for Student, Parent, Teacher, and Admin.

This is a frontend-only demo project:
- No real backend
- No real authentication
- No database
- No external API calls
- No server-side logic
- No persistent write actions

All pages, portals, dashboards, forms, charts, and admin controls must be built using static mock data and client-side rendering only.

Non-Goals / Constraints
- Do not build a real login or session system
- Do not connect to a real API or backend
- Do not use real payment processing
- Do not implement real uploads, posts, edits, deletes, or enrollments
- Do not use SSR or SSG; this must remain a static SPA
- Do not introduce any dependency that requires a runtime server

Tech Stack
- Framework: React 18 + Vite 7
- Language: TypeScript 5 (strict mode)
- Routing: Wouter
- Styling: Tailwind CSS v4 + tw-animate-css
- UI Components: shadcn/ui (button, card, dialog, input, label, select, separator, sheet, skeleton, sonner, textarea, toast, toggle, tooltip)
- Icons: Lucide React
- Forms: React Hook Form + Zod
- State/Data: TanStack Query
- Notifications: Sonner
- Fonts:
  - Headings: Playfair Display
  - Body/UI: Plus Jakarta Sans
- Package Manager: pnpm
- Monorepo: pnpm workspaces
- Build Target: Static SPA deployable on cPanel, Netlify, or Vercel

Project Type Definition
This project is a demo web application with:
